```bash
cd showcase
npm run dev
```

## 🎨 Design Philosophy & Features

1. **Top 1% Awwwards Aesthetic & Liquid Glassmorphism**:
   - Palette inspired by abyssal bioluminescence (`#030712`, `#38bdf8`, `#c084fc`, `#fab387`, `#a6e3a1`).
   - Apple VisionOS-spec frosted glass panels with specular highlights.
   - Editorial typography using Google Fonts (*Syne*, *Plus Jakarta Sans*, *JetBrains Mono*).

2. **Dual-Speed Persona Switch (Recruiter Fast-Track vs Staff Engineer Deep-Dive)**:
   - **Fast-Track (60s)**: High-level business ROI, 4 proof metrics, executive takeaways, and resume talking points.
   - **Deep-Dive (Staff Engineer)**: Mathematical formulation of local predictive coding surprise gating ($\Delta S_i = \|o_i - \hat{o}_i\|^2$), tensor dimensions, ONNX WASM SIMD execution, and interactive code explorer.

3. **Interactive 3D WebGL Cephalopod Connectome (Three.js)**:
   - Procedural undulating 8-arm cephalopod model with sucker receptors, central supraesophageal ganglion, and glowing interbrachial nerve ring.
   - Fluid mouse-cursor tracking and traveling electric action potential pulses.
   - Interactive synaptic firing trigger button (`⚡ Synaptic Spark`).

4. **Interactive Zero-Shot Amputation Sandbox**:
   - Recruiters can click `[Simulate Sudden Arm #3 Amputation]` to watch Arm #3 disintegrate into glowing embers.
   - Real-time telemetry dynamically updates: lateral nerve ring shifts to warning amber, rerouting communication across adjacent arms, while the remaining 7 arms compensate by increasing gait frequency to 1.45x with **0.00s downtime**.
   - One-click `[Regenerate Limb]` restores full connectome integrity.

5. **Interactive 5-Stage Cognitive Pipeline Stepper**:
   - Stage 1: Sensory Perception (8 peripheral patches).
   - Stage 2: Local Predictive Coding (Surprise metric $\Delta S_i$).
   - Stage 3: Event-Triggered Gating ($\le 22\%$ bandwidth cap).
   - Stage 4: Central Multi-Head Coalition Binding (`[Arms 1 ↔ 5]`).
   - Stage 5: Motor Actuation & Actor-Critic Value Assessment.

6. **1-Page Executive Technical Dossier (Print / Save PDF)**:
   - Recruiter-ready technical briefing formatted for hiring manager meetings.
   - Built-in `@media print` CSS rules generating a clean 1-page PDF dossier with one click.
