## 2. Failure Taxonomy & Root Cause Analysis

### Category A: Infrastructure & Routing Failures (Count: 3)
- **A.1 Hardcoded Cognitive Tier Mismatch (Count: 3):**
  - *Symptom:* `octoflow.errors.ProviderUnavailableError: [ollama] (HTTP 404) Model 'deepseek-coder-v2:16b' not found in Ollama`.
  - *Root Cause:* `octoflow/provider.py` hardcodes default models per cognitive tier (`tier == 'frontier'` defaults to `deepseek-coder-v2:16b`, `tier == 'fast'` defaults to `qwen2.5-coder:1.5b`). Arm 0 (Architect) is defined with `model_tier="frontier"`. When a user runs with a local model like `qwen2.5-coder:7b`, Arm 0 overrides the model selection and attempts to call an unpulled 16B model.
  - *Impact:* The run crashes immediately on the first arm step.

### Category B: Work Distribution & Decomposition Sizing (Count: 3)
- **B.1 Swarm Over-Proliferation on Targeted Tasks (Count: 3):**
  - *Symptom:* 8 concurrent arm executions scheduled for a small algorithmic task (e.g., Frontend Arm attempting `package.json`, DevOps Arm attempting `Dockerfile`, State Arm attempting React hooks).
  - *Root Cause:* `conductor.decompose_objective` unconditionally produces 8 subgoals regardless of task complexity. For targeted module challenges, idle arms should not call the LLM or compete for workspace files.
  - *Impact:* Wasted compute, high latency on local hardware, and cross-arm file collision (`temp.py`, `output.txt`, `README.md`).

### Category C: Tool-Call Syntax & Formatting Fragility (Observed in single-step probes)
- **C.1 Markdown Code Fences inside JSON String (Count: 1):**
  - *Symptom:* Model returns ` ```json { ... } ``` ` with conversational explanation prefix or suffix.
  - *Current Behavior:* Regex `r"```(?:json)?\s*(\{.*?\})\s*```"` fails if the JSON contains nested code or newlines that break the greedy group, falling back to heuristic `read_file README.md`.
- **C.2 Silent Fallback on Tool Parse Failure (Count: 1):**
  - *Symptom:* If parsing fails, `_parse_llm_action` falls back to `{"action": "read_file", "path": "README.md"}` rather than feeding a corrective tool validation error back to the arm.
  - *Impact:* Arm wastes cycles silently reading `README.md` instead of repairing its action JSON.

### Category D: Contract Adherence & Missing Imports (Count: 2)
- **D.1 Missing Standard Library Imports (Count: 1):**
  - *Symptom:* `NameError: name 'time' is not defined` when `time.time()` is called inside the generated rate limiter.
  - *Root Cause:* System prompt did not instruct the model that all files must be self-contained with explicit top-level imports.
- **D.2 Method Signature Mismatch (Count: 1):**
  - *Symptom:* `TypeError: allow_request() takes 2 positional arguments but 4 were given`.
  - *Root Cause:* Subgoal prompt said *"with allow_request(client_id, limit, window_sec)"*, but the 7B model assumed `limit` and `window_sec` should be stored in `__init__`. The prompt must explicitly specify parameter contracts and class definitions.

### Category E: Verification & Test Execution (Count: 3)
- **E.1 No Arm-Executed Tests Before Quiescence (Count: 3):**
  - *Symptom:* The arm writes the file and immediately marks quiescent without running tests.
  - *Root Cause:* No prompt instruction directing the arm to write a test file and execute `pytest` via `run_command` to verify its own code.

## 3. Prioritized Remediation Plan

In accordance with P3.2 requirements, fixes will be applied in separate, atomic commits:

1. **Commit 1: Fix Provider Tier Routing & Single-Model Enforcement:**
   - Honor `--model` across all cognitive tiers when a single model (such as Ollama local) is specified.
2. **Commit 2: Intelligent Work Distribution for Small Tasks:**
   - Active arm filtering: for canonical single-module / API tasks, decompose only to relevant arms (e.g. Backend + QA Tester); idle arms do not invoke the LLM.
3. **Commit 3: Robust Tool-Call Parsing & Corrective Feedback:**
   - Robust JSON extraction (fenced blocks, trailing comma repairs, nested brace matching).
   - Reject invalid/unknown tools with an actionable error message back to the arm's context.
4. **Commit 4: Clearer Arm System Prompts & Contract Guidance:**
   - Explicit instructions: workspace root, allowed tool schemas, self-contained imports (`import time`, etc.), and contract signatures.
5. **Commit 5: Test Execution & Verification Workflow:**
   - Instruct swarm to write unit tests and run `pytest` via `run_command` before quiescing.
6. **Commit 6: Cassette Recording & Replay Harness:**
   - Implement `--record-cassette <dir>` and `ReplayProvider` for offline CI execution.
