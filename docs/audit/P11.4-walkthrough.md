## 5. Open Code Issues Logged

### Issue 1: Add `jsonschema` to Dev Dependencies in `pyproject.toml`
- **Severity**: Low (Developer Onboarding Friction)
- **Description**: `tests/test_mcp_protocol.py` imports `from jsonschema import Draft202012Validator`. When setting up a fresh development environment using `pip install -e ".[dev]"`, `jsonschema` is not listed under `[project.optional-dependencies] dev` in `pyproject.toml`.
- **Recommended Fix**: Add `"jsonschema>=4.0.0"` to `dev` dependencies in `pyproject.toml` and re-generate `requirements.lock` via `make lock`.
