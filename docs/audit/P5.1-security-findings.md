# OctoFlow Security Review & Vulnerability Audit (P5.1)

**Audit Date:** 2026-10-31  
**Reviewer:** Application Security Reviewer  
**Branch:** `octos/p5-1-threat-model`  
**Scope:** OctoFlow core Python codebase, 3D WebGL visualizer, MCP architecture, CLI/TUI cockpit, CI/CD generator, and ignition runtime.

---

## 1. Executive Summary: Top 5 Security Risks

1. **Unscrubbed Parent Environment Inheritance in Ignition Runtimes (SEC-01 - Critical):**  
   `octoflow/ignition.py` spawns generated backend and frontend processes using `env = os.environ.copy()`. LLM-generated code and untrusted third-party dependencies immediately inherit the developer's full runtime environment, including `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GITHUB_TOKEN`, and cloud credentials.
2. **Stored Cross-Site Scripting (XSS) in Standalone Mission Audit Reports (SEC-02 - Critical):**  
   `octoflow/report.py` constructs standalone HTML reports by interpolating git commit branches, run objectives, arm findings, and raw code diffs directly into f-strings without `html.escape()`. Opening an exported audit report from an untrusted PR or repository executes arbitrary JavaScript in the developer's browser.
3. **Subprocess Execution with `shell=True` in Router Engine (SEC-03 - High):**  
   `octoflow/router.py` executes explicit shell commands (`!` prefix) via `subprocess.run(shell=True)`. Even with cockpit confirmation, chained shell commands (`cmd1 && cmd2`) or piped shell strings represent a critical command injection vector if confirmation is bypassed or non-interactively approved.
4. **Pre-Commit Hook Destruction Without Backup or Confirmation (SEC-04 - High):**  
   `octoflow/commands/guard.py` unconditionally overwrites `.git/hooks/pre-commit` during `octos install-hooks` or `octos onboard`, wiping out existing developer hooks (Husky, custom linters, security scanners) without backup or prompting.
5. **CI/CD Workflow Secret Exfiltration on Untrusted Pull Requests (SEC-05 - High):**  
   `octoflow/ci.py` generates GitHub Actions workflows that pass `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, and `GITHUB_TOKEN` to `pull_request` event triggers. In public or fork-enabled repositories, malicious pull requests can execute arbitrary code during tests to exfiltrate these repository secrets.

## 3. Severity Rationale

- **Critical:** Flaws that allow remote or untrusted local code execution or credential theft without user interaction (SEC-01 environment leakage to generated code; SEC-02 stored XSS in report files).
- **High:** Flaws that destroy developer workflows, facilitate command injection under specific conditions, expose CI secrets, or store private code world-readable (SEC-03, SEC-04, SEC-05, SEC-06).
- **Medium:** Protocol desynchronization, local unauthenticated eavesdropping, UI injection without direct host compromise, and known third-party vulnerabilities with limited local vectors (SEC-07, SEC-08, SEC-09, SEC-10, SEC-11).
- **Low:** Informational or edge-case configuration discrepancies (e.g. minor banner formatting or cosmetic error logs).

### 4.1 Bandit Static Analysis (`bandit -r octoflow -ll`)
- **Total Files Scanned:** 22,145 lines of Python code.
- **Findings Summary:** 1 High Severity, 4 Medium Severity.
- **Triage & True/False Positive Classification:**
  1. `octoflow/router.py:800`: `[B602:subprocess_popen_with_shell_equals_true]`  
     *Classification:* **TRUE POSITIVE**. `shell=True` is explicitly invoked for user shell routes. While mitigated by interactive prompt, it remains vulnerable to chaining and non-interactive bypass.
  2. `octoflow/server.py:214`: `[B104:hardcoded_bind_all_interfaces]`  
     *Classification:* **FALSE POSITIVE**. Comparison string check `if self.host not in ("127.0.0.1", "localhost", "0.0.0.0")` to whitelist origins; does not bind socket.

     *Classification:* **FALSE POSITIVE**. String check in Host header validation list.
  4. `octoflow/server.py:229`: `[B104:hardcoded_bind_all_interfaces]`  
     *Classification:* **FALSE POSITIVE**. Header comparison check.
  5. `octoflow/server.py:230`: `[B104:hardcoded_bind_all_interfaces]`
