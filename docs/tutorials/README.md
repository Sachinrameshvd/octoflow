# OctoFlow Step-by-Step Tutorials

Task-oriented, practical tutorials designed to get you productive with OctoFlow in under 10 minutes each. Every tutorial is verified against the live codebase.

---

## Available Tutorials

1. **[Tutorial 1: First Project with Local Ollama](01-first-project-with-ollama.md)**  
   *Duration: 7 mins* • Install Ollama, pull `qwen2.5-coder:7b`, run your first swarm mission, and test generated code.
2. **[Tutorial 2: Reading the Truthful Token Receipt](02-reading-the-token-receipt.md)**  
   *Duration: 5 mins* • Understand measured vs. estimated tokens, local avoided tokens, and per-arm cost breakdowns.
3. **[Tutorial 3: Undoing a Run with Atomic Git Rollback](03-undoing-a-run.md)**  
   *Duration: 4 mins* • How pre-flight checkpointing protects your repository and how to restore pre-flight state.
4. **[Tutorial 4: Building with a Custom 8-Arm Guild](04-building-with-a-custom-guild.md)**  
   *Duration: 8 mins* • Define, validate, and run domain-tailored 8-arm specialist rosters in pure JSON.
5. **[Tutorial 5: Adding a Custom LLM Provider](05-adding-a-custom-provider.md)**  
   *Duration: 9 mins* • Subclass `BaseLLMProvider`, register at runtime, and verify against `ProviderContractSuite`.
6. **[Tutorial 6: Using OctoFlow from Cursor & Claude Code via MCP](06-using-octoflow-from-mcp.md)**  
   *Duration: 6 mins* • Connect OctoFlow's stdio JSON-RPC server to Cursor and Claude Code.
7. **[Tutorial 7: Watching a Run in the 3D Connectome Visualizer](07-watching-in-the-visualizer.md)**  
   *Duration: 6 mins* • Launch `octoflow ui`, observe live synaptic transmission, and replay recorded missions.
8. **[Tutorial 8: Running Swarm Algorithmic Benchmarks](08-running-benchmarks.md)**  
   *Duration: 8 mins* • Measure token consumption across gated vs. ungated runs on standardized challenges.
