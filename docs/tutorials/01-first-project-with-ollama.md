# Tutorial 1: First Project with Local Ollama

**Estimated Duration:** 7 minutes  
**Verification:** Verified on 2026-11-09, OctoFlow v0.2.0  

This tutorial guides you through creating your first project using a local open-weight model (`qwen2.5-coder:7b`) with Ollama. Everything runs entirely on your machine with zero external network calls.

---

## Prerequisites

1. Install [Ollama](https://ollama.ai) and verify it is running:
   ```bash
   ollama --version
   ```
2. Pull the recommended local coding model:
   ```bash
   ollama pull qwen2.5-coder:7b
   ```
3. Verify your system readiness:
   ```bash
   octoflow doctor
   ```
   *Expected output: `Local Ollama: ONLINE (http://localhost:11434 | Models: qwen2.5-coder:7b)`.*

---

## Step 1: Initialize a Clean Workspace

Create a dedicated folder for your project and initialize Git (required for atomic checkpoints):

```bash
mkdir hello-octoflow
cd hello-octoflow
git init
```

---

## Step 2: Run a Swarm Mission

Ask OctoFlow to build a standalone Fibonacci sequence generator with pytest unit tests:

```bash
octoflow run "Create a fibonacci module with recursive and iterative implementations plus unit tests" --model ollama
```

## Step 3: Verify the Generated Deliverables

Inspect the files created by the autonomous specialist arms:

```bash
ls -la
```

Run the unit tests generated by Arm 5:

```bash
pytest test_fibonacci.py -v
```

*Expected output: All tests pass with 100% success rate.*

---

## Step 4: Safe Simulation Mode (Dry-Run)

If you ever want to preview how the swarm plans a mission without modifying your active workspace files, pass `--dry-run`:

```bash
octoflow run "Refactor fibonacci into a generator" --dry-run
```

All simulated output is isolated in `.octoflow/dry-run/` leaving your tracked repository files completely untouched.
