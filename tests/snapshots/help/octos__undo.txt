                                                                                                    
 Usage: octos undo [OPTIONS] [run_id]                                                               
                                                                                                    
 Undo an OctoFlow run: checkout original branch, discard run branch, and restore stash.             
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│   run_id      <str>  Specific run ID to undo (default: most recent run)                          │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --yes   -y             Skip confirmation prompt and proceed immediately                          │
